# Тестовые прогоны windows-cleanup

Журнал тестовых прогонов скилла: что гоняли, какие баги/UX-затыки нашли, что поправили.
Каждый прогон — отдельная секция с датой. Полная диагностика по шагам — в
`pc-cleanup-logs/<дата>/observations.md` рабочей папки прогона.

---

## Прогон 2026-08-18 (полный, фазы 0–10; версия скилла 0.2.1 → 0.2.2)

Среда: Windows 10 Pro 19045, PS 5.1, профиль планктон (кириллица), TEMP перенаправлен на D:.
Диски: C: 148 ГБ (свободно 51,6), D: 298 ГБ (свободно 136,8). Ctrl-диск — SATA SSD Kingston.

### Применено (по решениям пользователя)
- Тени C:: лимит UNBOUNDED → **10 ГБ** (`vssadmin resize /maxsize=10GB`): 16,9 → 5,82 ГБ использовано,
  свободное место C: 51,62 → 63,43 ГБ (**+11,81 ГБ**). D: теней нет.
- Автозапуски: MSIAfterburner и RazerCortexScheduleClean disabled, задача Nova удалена,
  RazerCortex снят с HKLM Run (100 → 98 живых; верифицировано повторным autostart.ps1).
- Мусор/кэши (~1,5 ГБ), программы, профиль, корзины — **не удалялись** (решение пользователя «ничего не удалять»).

### Найденные баги скилла (закрыты в 0.2.2)
1. `scan.ps1 -MinDupBytes 50MB` из командной строки падал
   (`ParameterArgumentTransformationError`: `"50MB" -> Int64 not in correct format`) — суффикс валиден
   только как литерал-дефолт в теле скрипта. → параметр стал строкой, парсинг через новую `ConvertTo-Bytes`
   (в `cleanup-common.ps1`): `'20MB'`, `'1.5GB'`, голые байты.
2. `scan.ps1` писал в фиксированные `dirs_top.txt/files_top.txt/dupes.txt` — второй скан (D:) затирал
   первый (C:). → параметр `-Tag 'c'`: имена `dirs_top_c.txt`, `dupes_d.txt`.
3. `shortcuts.ps1` ждал `-OutDir`, остальные phase-скрипты `-Work` (в тексте SKILL.md имя не было
   задокументировано). → параметр `-Work` с алиасом `-OutDir`.
4. `run-elevated.ps1 -Args` из git-bash не работал даже «словами раздельно» (bash срезает кавычки, PS
   видит `-Work` как параметр → PositionalParameterNotFound). → надежный мост: env `PC_ELEV_ARGS`
   построчно (одна строка = один аргумент). Памятка в шапке и Pitfall в SKILL.md переписаны.
   Замечание: первый вариант (Invoke-Expression `@(...)`) сам оказался багованым (`-Work` парсится как
   команда) — поймано верификацией, заменено.

### Открытые замечания (не патчили, кандидаты в 0.2.3)
- `inventory-quick.ps1`: колонка `installed.csv` названа `SizeMB`, но хранит сырой `EstimatedSize` в **КБ**
  (LoL выглядел как 39 ТБ вместо ~38 ГБ). Переименовать или делить на 1024.
- `ledger-report.ps1`: при 0 удалений строка «ИТОГО освобождено» печатает пустое число
  (`{0:N1}` на `$null` от `Measure-Object` пустого набора).
- Ворота дисков (Фаза 1): вопрос-тул с `multi_select=true` позволил пользователю выбрать противоречивую
  пару («Только C:» + «Оба») — предпочтительно radio (single-select), либо убрать «Оба».
- `scan.ps1`: пара Edge vs EdgeWebView2 (by-design дубль, 342 МБ, известный по inventory.md) попадает в
  `dupes.txt` пользовательских, а не в `dupes_system.txt` — добавить префикс в список системных.

### Агент-ошибки вызова из git-bash (обучающие кейсы)
- Экранированный `\$DATE` в пути не раскрывается (привет `pc-cleanup-logs$DATE`).
- `-Disks 'C','D'` → один аргумент `C,` — все кэши помечены «вне выбранных». Проверять кеш-флаги после запуска.
- `$` в `-Command "..."` из двойных кавычек bash съедаются → одинарные кавычки.
