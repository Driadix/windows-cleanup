# Фазовой машиной владеет скилл, todo — зеркало

Источник истины о фазах — процедура в SKILL.md: критерии завершения и ворота заданы там. Агент зеркалит прогресс в todo-инструмент для видимости и помечает шаг завершённым только после прохождения верификации (Test-Path / дельта). Отдельной «системы фаз» в todo нет — он отображает состояние, определённое скиллом. Отклонён вариант «todo диктует фазы»: тогда логика дублируется в двух местах и рассинхронизируется.
