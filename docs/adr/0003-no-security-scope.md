# Проверки безопасности исключены из скилла

Скилл занимается местом и мусором, а не безопасностью: никаких проверок Defender, сети/портов, DNS/hosts/прокси, поиска векторов персистентности, подписи автозапусков. Исключение — «неизвестное» (объект без происхождения): расследовать по дате/типу/подписи и спрашивать — но это часть дисциплины удаления, а не сканер угроз. Отклонено включение security-фаз: они раздувают скилл и провоцируют ложные срабатывания.
