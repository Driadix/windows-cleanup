# Полуавтоматический скилл: удаления только по явному согласию

Воркфлоу сознательно не автоматизирован до конца: необратимое (программы, данные, системные объекты) исполняется только после явного подтверждения пользователя, а мусор — только после показа размеров. Скорость принесена в жертву безопасности и предсказуемости: ценность воркфлоу — в решениях пользователя, а не в скорости агента. Полная автоматизация отклонена как вариант.
