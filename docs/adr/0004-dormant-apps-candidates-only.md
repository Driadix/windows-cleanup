# Детекция неиспользуемых: только кандидаты, никогда авто-удаление

Поиск давно не запускавшихся программ (UserAssist/Prefetch/MuiCache/InstallDate) выводит список «возможно, не используется» с пометкой риска и последнего запуска — и всё. Такие записи никогда не входят в список на удаление по умолчанию: решение всегда за пользователем. Авто-удаление «неиспользуемых» отклонено: сигналы по отдельности недостоверны (переустановки, вызовы из планировщика, portable с D:, лаунчер-игры без собственного следа).
