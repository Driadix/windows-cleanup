# Windows Cleanup Skill

Полуавтоматическая очистка Windows 10/11 через ИИ-агента: инвентаризация, мусор и кэши, удаление программ по выбору, сироты и автозапуски, битые ярлыки. Каждое необратимое действие — через **ворота явного согласия** пользователя.

> **Версия:** 0.2.1 · **Лицензия:** MIT · **Платформа:** Windows (только)

## Что это

Скилл для агентов с поддержкой скиллов (Hermes, Claude Code, Codex и аналогичных) — рабочий процесс освобождения места на диске. Агент ведёт очистку по фазам, сам собирает факты (карты папок, крупнейшие файлы, установленные программы, кэши, корзины, дубли, Steam-игры, признаки «давно не запускавшегося»), составляет отчёт с размерами и рисками. **Удаляется только то, что пользователь явно выбрал.**

Работает по принципу «сначала факты, потом действие»: каждая фаза фиксируется в журнале (ledger), итог строится по дельте «свободное место: было X → стало Y, освободилось N ГБ».

**Скилл НЕ автоматический.** Между фазами — обязательные точки согласия. Агент не удаляет программу, данные, сейвы или «неизвестный» файл без решения пользователя; системные операции (отключение гибернации, DISM) выполняются только с объяснением последствий.

**Скилл НЕ занимается безопасностью и производительностью.** Никаких антивирусных проверок, сканирования сети и портов, «оптимизаций» — только освобождение места и удаление мусора.

## Возможности (фазы воркфлоу)

| Фаза | Что делает |
|---|---|
| 0–1 | Контекст (ОС, диски, права) + выбор дисков под очистку |
| 2 | Инвентаризация: карты папок, топ файлов, программы, установщики, корзины, дубли, Steam, кандидаты «возможно не используется» |
| 3 | Отчёт по протоколу списка: №-ID, путь, размер, риск; ворота согласия по каждому блоку |
| 4 | Мусор и кэши: user-проход → elevated-проход через один UAC → DISM |
| 5 | Программы: удаление по списку с обязательной проверкой остатков (residue-check) |
| 6 | Профиль и данные: сироты AppData/ProgramData; сейвы — отдельный вопрос с предупреждением |
| 7 | Автозапуски: полный список со статусами и предложениями (удалить/отключить/оставить) |
| 8 | Битые ярлыки (.lnk/.url) в 4 стандартных местах |
| 9 | Рекомендации: системные опции с объяснением + штатные команды Windows |
| 10 | Итог: свод из журнала — было/стало, освобождено по фазам, что осталось на потом |

Полное описание воркфлоу и всех нюансов — в [SKILL.md](windows-cleanup/SKILL.md) (на русском).

## Принципы

- **Ворота согласия**: необратимое — только после явного решения пользователя; «неизвестное» сначала расследуется и показывается; без показа пользователю не удаляется.
- **Учёт дельты**: baseline свободного места фиксируется в начале, каждый итог — «свободное место: было X → стало Y, освободилось N ГБ».
- **Кросс-чеки**: папка не удаляется, пока не сверен реестр; после деинсталляции результат проверяется отдельно (exit-код не считается достаточным подтверждением).
- **UAC-дисциплина**: админские действия собираются в батчи, ≤2 UAC-прохода за сессию.
- **Кириллица**: пути с кириллицей — только через `-LiteralPath`, логи — в UTF-8.

## Состав репозитория

```
disk-cleanup/
├── windows-cleanup/          # сам скилл (копируй целиком)
│   ├── SKILL.md              # инструкция для агента (главный файл)
│   ├── scripts/              # PowerShell-помощники (12 шт.)
│   └── references/           # справочники фаз (4 шт.)
├── tools/                    # для разработчиков: validate.py, smoke_test.ps1
├── docs/                     # ADR-решения + заметки тестовых прогонов
└── CONTEXT.md                # контекст и словарь проекта
```

Для работы скиллу нужна **вся папка `windows-cleanup/` целиком** (scripts/ и references/ обязательны — ставить один SKILL.md без них нельзя).

## Установка

### Человеку (вручную)

1. **Скачай репозиторий**: зелёная кнопка **Code → Download ZIP** (или `git clone https://github.com/Driadix/windows-cleanup.git`).
2. **Найди папку скиллов своего агента.** Обычно это:
   - Hermes: `%LOCALAPPDATA%\hermes\skills\` (например `C:\Users\Имя\AppData\Local\hermes\skills\`)
   - Claude Code / Codex и другие: `~\.claude\skills\`, `~\.codex\skills\` — точный путь подскажет сам агент.
3. **Скопируй папку `windows-cleanup` целиком** в категорию `maintenance`:
   ```
   %LOCALAPPDATA%\hermes\skills\maintenance\windows-cleanup\
   ```
   Категорию создай, если её нет.
4. **Проверь**: в Hermes — `hermes skills list` (должен появиться `windows-cleanup`), для загрузки инструкции в чат попроси агента «почисти комп».

Опциональная проверка целостности: `python tools/validate.py` — прогонит статическую валидацию скилла.

> Используешь Hermes — установку может сделать сам агент, см. ниже — это проще.

### Агенту (любой агент с поддержкой скиллов)

Отправь агенту ссылку на этот репозиторий и попроси установить. Пример формулировки:

> Установи скилл `windows-cleanup` из репозитория https://github.com/Driadix/windows-cleanup. Собери папку `windows-cleanup` (SKILL.md + scripts/ + references/) целиком в свой каталог скиллов и подтверди установку списком загруженных файлов.

Для Hermes-агентов можно явно:

```
hermes skills tap add Driadix/windows-cleanup
git clone --depth 1 https://github.com/Driadix/windows-cleanup.git "$LOCALAPPDATA/Temp/disk-cleanup"
cp -r <клон>/windows-cleanup "$LOCALAPPDATA/hermes/skills/maintenance/windows-cleanup"
hermes skills list | grep windows-cleanup    # проверка
```

(Альтернатива — `hermes skills install https://github.com/Driadix/windows-cleanup`, но этот способ может не установить файлы, явно не упомянутые в SKILL.md; полное копирование надёжнее — скилл остаётся редактируемым).

После установки напиши агенту: **«почисти комп»** или **«освободи место»** — он подхватит скилл и проведёт по фазам, останавливаясь перед каждым удалением.

## Ограничения и исключения

- Только **Windows 10/11**, PowerShell 5.1+.
- Не работает с macOS/Linux.
- Не занимается безопасностью (антивирус, сеть, порты) и не «разгоняет» систему.
- Ничего не удаляет без явного согласия пользователя; сценарии полной автоматизации без контроля не предусмотрены.
