# Final Options — Фазы 9–10 (системное, встроенные команды, детекция неиспользуемых)

Справочник на требование. Всё в этой теме — **предложения, не действия**: решение пользователя обязательно.

## Блок «Системное» (риск-опции, только с объяснением последствий)

| Опция | Команда | «На что влияет» / условие рекомендации |
|---|---|---|
| Отключить гибернацию | `powercfg /h off` | Удалит `hiberfil.sys` ≈ 40% RAM; гибернация и «быстрый запуск» отключатся. Рекомендовать только если место важнее фичи. |
| Глубокая DISM | `dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase` | Сжимает WinSxS сильнее, но убирает возможность отката обновлений. |
| Ограничить тени | `vssadmin list shadowstorage` → `vssadmin resize shadowstorage /for=C: /on=C: /maxsize=10GB` | Ограничит точки восстановления. |
| Удалить драйвер | `pnputil /enum-drivers` → `pnputil /delete-driver oemXX.inf /uninstall` | Только когда драйвер очевидно не нужен. |
| WSL-компонент | `wsl --uninstall` (админ) + перезагрузка | Освобождает `C:\Program Files\WSL`, но убирает сам WSL. |

Порядок: объяснить → спросить → при «да» исполнить в тот же UAC-батч (не отдельными промптами).

## Встроенные команды (действия пользователя — объяснить, как запустить)

```powershell
cleanmgr /sagerun:1            # тихий «Очистка диска» по сохранённому профилю (сначала cleanmgr /sageset:1)
cleanmgr /d C:                 # GUI с галочками
start ms-settings:storagesense # Win11: рекомендации Storage Sense
chkdsk /scan                   # read-only проверка, без перезагрузки
optimize-volume -DriveLetter C -ReTrim   # TRIM для SSD
Get-PhysicalDisk | Select HealthStatus   # здоровье дисков
```

**Никаких предложений установки сторонних тулов** (WizTree/TreeSize/WinDirStat) скилл не делает — если пользователь спросит, найди сам в вебе без скилла.

## Детекция неиспользуемых (предложить после фаз; только кандидаты — ADR 0004)

Предложение в конце стандартного запуска: «хочешь, найду программы, которые давно не запускались?»

**Сигналы (по одному недостоверны, вместе — надёжно):**
1. **UserAssist** — `HKCU\...\Explorer\UserAssist\{GUID}\Count`: имена ROT13 (декод `[char]([int][char]$c - 13)`) — доступ к датам нестабилен, считать только факт отсутствия запуска;
2. **Prefetch** — `C:\Windows\Prefetch\*.pf`: LastWriteTime ≈ последний запуск;
3. **MuiCache** — `HKCU\...\Shell\MuiCache`: факт запуска (без дат);
4. **Реестр Uninstall** — InstallDate, InstallLocation, размер;
5. **Отрицательные фильтры** — не в автозапуске, процесс не запущен, LastWriteTime папки > 180 дней.

**Комбо-правило кандидата:** установлена > 180 дней И нет следа запуска за 180 дней И не в автозапуске И размер > 100 МБ → «возможно, не используется — решаешь ты».

**Оговорки (не предлагать в список по умолчанию):** переустановленные приложения; вызовы из планировщика/скриптов (проверить задачи!); разовые утилиты; portable с данных дисков; игры, запускаемые через чужие лаунчеры (без собственного следа).
