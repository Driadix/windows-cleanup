# Final Options — Фазы 9–10 (системное, встроенные команды, детекция неиспользуемых)

Справочник на требование. Всё в этой теме — **предложения, не действия**: решение пользователя обязательно.

## Блок «Системное» (риск-опции, только с объяснением последствий)

| Опция | Команда | «На что влияет» / условие рекомендации |
|---|---|---|
| Отключить гибернацию | `powercfg /h off` | Удалит `hiberfil.sys` ≈ 40% RAM; гибернация и «быстрый запуск» отключатся. Рекомендовать только если место важнее фичи. |
| Глубокая DISM | `dism /Online /Cleanup-Image /StartComponentCleanup /ResetBase` | Сжимает WinSxS сильнее, но убирает возможность отката обновлений. |
| Ограничить тени | `vssadmin list shadowstorage` → `vssadmin resize shadowstorage /for=<DL>: /on=<DL>: /maxsize=10GB` | Ограничит точки восстановления. Замер уже делает `elevated-cleanup.ps1` → `shadowstorage.txt` (в прогоне 2026-08-18 C: было 16 ГБ при UNBOUNDED). `<DL>` — буква тома из Фазы 1, НЕ всегда C:. |
| Удалить драйвер | `pnputil /enum-drivers` → `pnputil /delete-driver oemXX.inf /uninstall` | Только когда драйвер очевидно не нужен. |
| WSL-компонент | `wsl --uninstall` (админ) + перезагрузка | Освобождает `$env:ProgramFiles\WSL`, но убирает сам WSL. |
| Убрать Windows.old | флаг `-WindowsOld` у `elevated-cleanup.ps1` (или «Очистка диска» → «Предыдущие установки Windows») | Десятки ГБ после крупного обновления, НО убирает возможность откатиться на прежнюю версию ОС. Только с явным согласием. |

Порядок: объяснить → спросить → при «да» исполнить в тот же UAC-батч (не отдельными промптами).

## Встроенные команды (действия пользователя — объяснить, как запустить)

# Буквы дисков подставляй из Фазы 1 (контекст), а не 'C:' по умолчанию — система может стоять не на C:.
cleanmgr /sagerun:1                    # тихий «Очистка диска» по сохранённому профилю (сначала cleanmgr /sageset:1)
cleanmgr /d <DL>:                      # GUI с галочками для нужного тома
start ms-settings:storagesense         # Storage Sense: есть и в Win10 1703+, и в Win11 (не «только Win11»)
chkdsk <DL>: /scan                     # read-only проверка тома, без перезагрузки
optimize-volume -DriveLetter <DL> -ReTrim   # TRIM для SSD
Get-PhysicalDisk | Select HealthStatus      # здоровье дисков

Формулировки итогов — только «свободное место: было X → стало Y, **освободилось N ГБ**» (никогда «размер стал больше/меньше» без уточнения, что именно свободно).

**Никаких предложений установки сторонних тулов** (WizTree/TreeSize/WinDirStat) скилл не делает — если пользователь спросит, найди сам в вебе без скилла.

## Детекция неиспользуемых (встроена в фазы; только кандидаты — ADR 0004)

Не отдельное «предложение в конце»: кандидаты собираются артефактом **`unused_hints.txt` в Фазе 2** (сигналы ниже) и показываются в **Фазе 3 как блок 🔵** и в кандидатах **Фазы 5** как «возможно не используется — решаешь ты». Фаза 10 остаётся итогом (свод из `ledger.csv`) без отдельного скана.

**Сигналы (по одному недостоверны, вместе — надёжно):**
1. **UserAssist** — `HKCU\...\Explorer\UserAssist\{GUID}\Count`: значения лежат в подключе **`Count`**, а не в самом `{GUID}` (чтение `{GUID}` даёт 8 служебных свойств и 0 путей — сигнал полностью мёртв; исправлено в прогоне 2026-10-03). Имена ROT13 (декод `[char]([int][char]$c - 13)`, вращаются только буквы) — доступ к датам нестабилен, считать только факт отсутствия запуска;
2. **Prefetch** — `$env:SystemRoot\Prefetch\*.pf`: имя `APP.EXE-1A2B3C4D.pf`, LastWriteTime ≈ последний запуск. **На SSD Prefetch/Superfetch часто выключен и читается только админом → 0 файлов означает «сигнал недоступен», а НЕ «не использовалось»** (`unused-detect.ps1` печатает эту оговорку явно);
3. **MuiCache** — `HKCU\...\Shell\MuiCache`: факт запуска (без дат);
4. **Реестр Uninstall** — InstallDate, InstallLocation, размер;
5. **Отрицательные фильтры** — не в автозапуске (Run/RunOnce всех веток + Startup-папки user/ProgramData + задачи + авто-службы `StartMode=Auto`), процесс не запущен, LastWriteTime каталога установки > 180 дней, локация не общий каталог и не Steam-библиотека.

**Комбо-правило кандидата:** LastWriteTime каталога установки > 180 дней И нет следа запуска (MuiCache/UserAssist\Count/Prefetch) И не в автозапуске (Run/RunOnce + Startup-папки + задачи + авто-службы) И не запущен процесс И размер > 100 МБ (`-MinMB`) → «возможно, не используется — решаешь ты». Общие каталоги (`Program Files`, корень тома, профиль) и Steam-библиотеки не проверяются вовсе.

**Оговорки (не предлагать в список по умолчанию):** переустановленные приложения; вызовы из планировщика/скриптов (проверить задачи!); разовые утилиты; portable с данных дисков; игры, запускаемые через чужие лаунчеры (без собственного следа).
