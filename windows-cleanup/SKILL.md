# Windows Cleanup Skill

Полуавтоматический воркфлоу освобождения места на Windows 10/11: инвентаризация, очистка мусора и кэшей, удаление программ по выбору пользователя, зачистка профиля/остатков/автозапусков, битых ярлыков. Скилл **не** автоматический: каждое необратимое действие проходит через **ворота** — явное решение пользователя. Скилл **не** занимается безопасностью (никаких проверок антивируса, сети, портов) — только место и мусор. Цель — место, не производительность.

Язык общения с пользователем — русский. Все пути — с учётом кириллического профиля (`-LiteralPath` везде).

## When to Use

- «Почисти комп / освободи место / убери мусор, кэши, лишние программы»
- «Что можно почистить / что у тебя есть?» → отвечай списком фаз с оценочными результатами, затем по выбору пользователя
- Точечная просьба → входи ровно в нужную фазу («почисти корзину / браузер», «найди дубли», «проверь автозагрузку»)

**Don't use for:** macOS/Linux (вообще не наш случай); антивирусные проверки и «поиск вредоносного»; разгон/оптимизация производительности; полномасштабная автоматизация без контроля пользователя.

## Prerequisites

- Windows 10 или 11, PowerShell 5.1+. Детектируй ОС сам: `Get-CimInstance Win32_OperatingSystem` (Caption, BuildNumber) + `$PSVersionTable` — ветвление Win10/11 только по 4 пунктам: winget, Teams, WSL из Store, Storage Sense. Пользователя про ОС не спрашивай.
- **Права**: стартуем пользовательской сессией. Админ нужен → не просим заранее, а говорим «сейчас появится окно UAC — подтверди» и запускаем `Start-Process -Verb RunAs -PassThru -Wait`.
- **Рабочая папка** (логи/скрипты/результаты сканов): `%USERPROFILE%\Documents\PC-Cleanup\<дата>\`. Если у текущей сессии есть явный рабочий каталог проекта — клади логи в него в подпапку `pc-cleanup-logs\`. **Никогда** не в %TEMP% (TEMP — цель очистки и часто перенаправляется). Рабочая папка **исключена из очистки**.
- `%TEMP%` берём только из `$env:TEMP`, никогда не хардкодим путь.

## How to Run

Полный воркфлоу — процедура ниже, фазы 0–10. Точечный запрос — нужная фаза(ы): контекст (0) и ворота дисков (1) проходятся быстро, затем целевая фаза. Скрипты-помощники лежат рядом со скиллом в `scripts/`; путь к папке скилла — `skill_view` (поле `skill_dir`) или `${env:USERPROFILE}\AppData\Local\hermes\skills\maintenance\windows-cleanup\`. Запуск: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<skill_dir>\scripts\<имя>.ps1" <аргументы>`.

| 1 Ворота дисков | какие диски чистим (если >1 и не сказано) | явный список целевых дисков |
| 2 Инвентаризация | карты папок, топ файлов, программы, установщики, корзины, дубли | все цели отсканированы |

| 5 Программы | удаление по списку + чек-лист остатков | всё решённое удалено или LOCKED-pending |
| 6 Профиль и данные | AppData*/ProgramData/профиль: сироты; сейвы — отдельные ворота | каждый остаток помечен после кросс-чека |

## Procedure

Каждая фаза заканчивается **критерием завершения**; между фазами не останавливаемся без необходимости. Останавливаемся **только на воротах**. После каждой фазы — запись в **per-phase лог** и **кумулятивный репорт-файл** (UTF-8): фаза, что удалено, сколько освобождено накопительно. Прогресс зеркалится в todo-инструмент; шаг помечается completed **только после прохождения верификации**.

### Фаза 0. Контекст
`Get-CimInstance Win32_OperatingSystem`, `whoami`/`$env:USERPROFILE`, `Get-Volume | Where DriveLetter`, `$env:TEMP`, проверка текущих прав (`IsInRole('Administrators')`). Создай рабочую папку. Запиши контекст первой строкой лога.
**Критерий:** карта дисков (буква, метка, размер, свободно, DriveType) и версия ОС — в логе; рабочая папка создана.

### Фаза 1. Ворота дисков
Дисков >1 и пользователь не уточнил → **стоп, вопрос-тул с мультивыбором**: перечисли диски с DriveType и размером; съёмные (Removable) и сетевые (Network) исключены по умолчанию, их можно включить только явно. Корзины чистим только по выбранным дискам.
**Критерий:** явный список целевых дисков зафиксирован в контексте.

### Фаза 2. Инвентаризация
Независимые сканы — параллельно. Источники и команды — `references/inventory.md`. Собери:
- карты папок (топ-50 по размеру) на целевых дисках + ProgramData + AppData*;
- топ крупных файлов;
- список программ из 3 веток реестра Uninstall (HKLM + WOW6432Node + HKCU);
- установщики в Desktop/Downloads/Documents;
- корзины по выбранным дискам;
- кандидаты дубликатов (группировка Name+Length, фильтр >50 МБ, хеш только кандидатов).

**Критерий:** по каждой цели результат записан в файлы сканов в рабочей папке; ни одна цель не удалена.

### Фаза 3. Отчёт + ворота согласия
Составь отчёт по **протоколу списка**: таблицы-блоки, у каждой строки №-ID, путь, размер, риск (🟢 мусор/кэш · 🟡 программа· 🔴 данные), рекомендация. Покажи **итог сверху** и подытоги по категориям. Представь пользователю решение: «удалить 1,2,5-7» / «все кроме 3,8» / «только 4». Короткие списки (<10) — продублируй в вопрос-тул с мультивыбором.
**Ворото-правила:**
- «Мусор/кэши» — можно группой **после показа размеров**;
- «Программы» — всегда список → вопрос;
- «Данные/сейвы» — отдельный вопрос с предупреждением о риске;
- «Системное» — только с объяснением (см. Фаза 9);
- **«Неизвестное»** (объект без происхождения, как `C:\Windows\392667600.dat`) — расследовать (дата создания, тип, подпись, происхождение) → показать → спросить. **Удалять нельзя молча.**
**Критерий:** по каждому блоку есть явное решение пользователя, зафиксированное в контексте.

### Фаза 4. Мусор и кэши
Точки мусора и команды — `references/cleanup.md`. Сначала user-проход (temp, кэши пакетных менеджеров, браузерные Cache, корзины по выбранным дискам, установщики по списку). Затем собери всё elevated в **один проход** (Windows\Temp, Dbz*, SoftwareDistribution, DISM `/StartComponentCleanup`) → «сейчас появится окно UAC — подтверди» → `Start-Process -Verb RunAs -PassThru -Wait` → прочитай лог скрипта (не консоль). Удаление — **группами**, одним батчем, не растаскивай на одиночные UAC-спамы.
**Критерий:** по каждой цели `Test-Path` → `removed` / `already gone` / `LOCKED`; дельта зафиксирована; невыполненное (LOCKED) помечено и попадает в итог.

### Фаза 5. Программы
Удаление строго по списку:
- определяй тип (MSI/Inno/NSIS/Squirrel/InstallShield/UWP/Portable/Steam/WSL/LocalDB/служба) — таблица и тайм-ауты в `references/cleanup.md`;
- останови процессы и службы до удаления;
- после каждой — **чек-лист остатков**: процессы → службы → задачи → Run-ключи → ярлыки → папки → реестр (HKLM+WOW6432+HKCU). **Папку не удалять, пока не сверен реестровый кросс-чек** (в своих каталогах вроде `D:\Soft` соседние приложения живут рядом);
- MSI-установки — во второй elevated-проход (в идеале сессия тратит **≤2 UAC-прохода** всего, жёсткий потолок — 3).
**Критерий:** каждая выбранная программа → удалена / `LOCKED`-pending (с пометкой) / «не удалена по решению пользователя»; лог + Test-Path по каждой.

### Фаза 6. Профиль и данные
Обход AppData Local/Roaming/LocalLow + ProgramData + корень профиля (со скрытыми). Карта и кросс-референс папка ↔ установлено — `references/deep.md`. Сироты (папки/данные без установленного владельца) собираются в блок. **Сейвы** (LocalLow по студиям, My Games, Saved Games) — категория «спорное»: **отдельный вопрос**, риск-класс 🔴.
**Критерий:** каждый остаток помечен «удалён» или «оставлено (решение)» — после реестрового кросс-чека перед удалением папки.

### Фаза 7. Автозапуски
Все источники: Run/RunOnce (HKCU+HKLM+WOW6432Node), Startup-папки (user+ProgramData), задачи (`TaskPath -notlike '\Microsoft\Windows\*'` + Actions), службы Auto, Winlogon, StartupApproved — команды в `references/deep.md`. **Каждая запись → `Test-Path` цели**; живые остаются, битые удаляются.
**Критерий:** по каждой записи решение (живая/битая), битые удалены, отчёт в лог.

### Фаза 8. Битые ярлыки
Desktop user+Public, Start Menu user+ProgramData; `.lnk` и `.url`. Скрипт `scripts/shortcuts.ps1`. Битые = цель не существует.
**Критерий:** все ярлыки проверены, битые удалены, сосчитаны (напр. «65 битых, 212 целых»).

### Фаза 9. Рекомендации
Два блока (всё из `references/final-options.md`):
- **Системное** (риск-опции): `powercfg /h off` (hiberfil ≈ 40% RAM — объяснить: «отключит гибернацию», рекомендация только если место важнее фичи), DISM `/ResetBase` (без отката обновлений), `vssadmin resize`, удаление драйверов. Каждая — с «на что влияет» + условием рекомендации; выполнение только по явному «да» с осознанием последствия, желательно в тот же UAC-батч.
- **Встроенные команды** (действия пользователя, объяснить как запустить): `cleanmgr /sagerun:1`, `chkdsk /scan`, `Optimize-Volume -ReTrim`, Storage Sense.
**Никаких предложений установки сторонних инструментов** (WizTree и т.п.) — если пользователь спросит, реши ad hoc без скилла.
**Критерий:** каждая опция объяснена; одобренное исполнено или зафиксировано «отложено».

### Фаза 10. Итог
`Get-Volume` до/после, дельта по дискам. Итоговый отчёт: «было/стало» → удалено по категориям (с суммами) → **оставлено осознанно** (с причинами) → **требует перезагрузки/действия** (LOCKED-pending, PendingFileRenameOperations, `wsl --uninstall`) → советы. Запиши отчёт в кумулятивный файл и покажи. В конце предложи **детекцию неиспользуемых** (только кандидаты, решает пользователь; сигналы и оговорки — в `references/final-options.md`).
**Критерий:** отчёт записан в файл + показан; каждая фаза имеет запись в кумулятивном репорте.

## Pitfalls

- **`Del` — алиас `Remove-Item`**: функция с именем `Del` молча не вызывается. Используй имя `Remove-Target` и явные `-LiteralPath -Recurse -Force`. (Это стоило повторного прохода.)
- **`-LiteralPath` всегда** — кириллица, пробелы, скобки.
- **После каждого удаления — `Test-Path`**: `removed / LOCKED / already gone`. `SilentlyContinue` прячет провалы — не полагайся на него.
- **LOCKED-процедура**: ретрай → `Stop-Process` держателя → остановка SearchIndexer (часто не помогает) → `scripts/pending-delete.ps1` (PendingFileRenameOperations — удаление при перезагрузке).
- **UAC-дисциплина**: не спамим. Один промпт на проход, цель ≤2 прохода/сессия. Отменённый UAC → «не выполненное» в отчёт, продолжить на доступном, спросить в конце один раз; повторный промпт — **только по явной просьбе**.
- **Тайм-ауты**: MSI 240–300 с; elevated-проход целиком 30–50 мин; сканы 10–30 мин; независимое — параллелить.
- **Логи UTF-8** — иначе кириллица битая; читаем лог, а не консоль.
- **%TEMP% не хардкодить**; рабочая папка — никогда не удалять.
- **Неизвестное на системных томах** (корень `C:\Windows`, корни дисков): перед удалением проверить дату создания, тип, подпись, происхождение — и спросить.
- **Не удалять данные установленных приложений** — реестровый кросс-чек до удаления папки.
- **settings-less тихие установщики**: если папка уже удалена, антинсталлер может вернуть «MISSING» — это не ошибка, чистим реестр.

## Verification

- Для каждой фазы: `Get-Volume` до/после → дельта → запись в per-phase лог + кумулятивный репорт.
- Для каждого удаления: `Test-Path` → статус.
- Итог: `Get-Volume` по целевым дискам «было/стало»; свод «освободилось N ГБ»; сверка «не удалено по решению: …».
- Todo-шаг помечается completed только после прохождения верификации этой фазы.
