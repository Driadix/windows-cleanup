# Windows Cleanup Skill (воркфлоу очистки ПК)

Контекст проекта: проектирование скилла `windows-cleanup` для Hermes-агента — полуавтоматического воркфлоу поиска и удаления непотребного на Windows 10/11 (мусор, кэши, установщики, программы, сироты). Рабочий язык документации и общения — русский.

## Согласие и безопасность

**Фаза**:
Отрезок воркфлоу со своим проверяемым критерием завершения; нумерация 0–7.
_Avoid_: этап, шаг (общие слова без критерия).

**Ворота (согласия)**:
Обязательная точка, где агент останавливается и получает решение пользователя перед необратимым действием. Останавливаться на воротах можно, между фаз — нельзя.
_Avoid_: подтверждение (широкое слово, размывает ворота).

**Риск-класс**:
Категория удаления, определяющая тип ворот: Мусор (можно группой после показа размеров) / Программа (всегда вопрос со списком) / Данные (вопрос с предупреждением риска) / Системное (только с объяснением последствий и явным «да»).

**Elevated-проход**:
Один батч всех действий, требующих админа, через один UAC-промпт; правило — в идеале ≤2 прохода за сессию. Всё, что можно сделать в пользовательской сессии, делается вне проходов.

**Рабочая папка**:
Папка, где агент ведёт логи и скрипты; всегда исключается из очистки.

**Неизвестное**:
Объект без установленного происхождения (файл/запись). Правило: расследовать (дата, тип, подпись, происхождение) → показать → спросить. Удалять нельзя.

## Объекты очистки

**Мусор / Кэш**:
Данные, безопасно регенерируемые или бесполезные (temp, кэши пакетных менеджеров, браузерные кэши, корзины) — риск-класс «Мусор».

**Установщик**:
Инсталлятор (.exe/.msi/.zip-пакеты) в пользовательских папках; никогда не авто-удаляется — только по списку с размером и датой; дубликат можно сократить до одной копии.

**Программа**:
Установленный софт со своей записью деинсталляции; удаляется только по явному выбору пользователя из списка.

**Сирота**:
Остаток от отсутствующего приложения (папка, реестровая запись, задача, служба, ярлык). Папку не удалять, пока не сверен реестровый кросс-чек.
_Avoid_: «хвост», «остаток» (в диалоге — то же самое, но канон один).

**Битый ярлык**:
Ярлык/ссылка (.lnk/.url), чья цель не существует (Test-Path = false). Живые ярлыки не трогаются.
_Avoid_: «битая ссылка», «мёртвая иконка» — то же самое.

**Детекция неиспользуемых**:
Необязательный проход после стандартных фаз: поиск программ «давно не запускавшихся» по совокупности сигналов (UserAssist/Prefetch/MuiCache/InstallDate + отрицательные фильтры). Результат — только кандидаты; решение — всегда за пользователем, само удаление исключено.

**Встроенные команды**:
Стадия предложений безопасных штатных утилит Windows (cleanmgr, chkdsk /scan, Storage Sense, Optimize-Volume -ReTrim и т.п.), которые пользователь может запустить сам. Предложения установки сторонних инструментов в скилле нет.

## Контроль прогресса

**Дельта**:
Измеряемое изменение свободного места до/после фазы; обязательна в отчёте («было/стало»).

**LOCKED**:
Состояние цели, не удалившейся из-за блокировки процессом/системой; завершающий приём — удаление при перезагрузке (PendingFileRenameOperations).

**Протокол списка**:
Формат представления кандидатов на удаление: №-ID, путь, размер, риск, рекомендация; ответ пользователя парсится номерами и диапазонами («все кроме 3,8»).
